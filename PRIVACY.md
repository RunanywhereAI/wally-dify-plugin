# Privacy Policy

This plugin connects Dify to Wally, the hosted inference API run by RunAnywhere, Inc. (`https://inference.runanywhere.ai/v1`).

## What the plugin sends

When a Dify app uses a Wally model, the plugin sends the request to Wally so the model can answer: prompts, conversation messages, tool definitions and tool results, and images you attach to a vision model. It authenticates with the Wally API key you enter in Dify. No other endpoint is called.

## What the plugin stores

The plugin itself stores nothing. It keeps no logs, analytics or copies of your content. Dify stores your API key as an encrypted credential, the same way it stores credentials for every model provider.

## How Wally handles the data

Wally uses zero data retention for prompt and completion text: RunAnywhere does not store the text you send to a model or the text it returns. RunAnywhere keeps usage records (token counts, timestamps, model, request ID and spend) for billing, abuse prevention and support. RunAnywhere does not sell your data.

Full policy, including the processors that run parts of the service: https://www.runanywhere.ai/legal/privacy
